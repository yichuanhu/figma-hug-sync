# 公有云视觉体系统一计划

## 目标
公有云与私有部署保持为同一产品在不同环境下的两个入口。公有云保留独立业务代码与功能，但完整继承当前 APA 项目的品牌、导航、色彩、图标、组件和页面节奏，不再另做一套视觉。

## 调整范围

### 1. 统一整体框架
- 公有云侧栏对齐当前项目侧栏：相同 Logo 尺寸、背景色、菜单尺寸、选中态、圆角与图标线宽。
- 页面外层对齐当前首页：浅灰页面背景、白色内容区域、顶部蓝色淡晕影、24px 内容间距和内部滚动方式。
- 页面标题、说明文字、Tabs 和内容起始位置统一现有管理页面规范。

### 2. 重做公有云首页视觉
- 删除当前独立的“大边框工作台”表达，改为当前首页同款白色模块组合。
- 产品入口采用“快速开始”同款柔和彩色浅底卡片，图标色使用现有项目的紫、粉、橙、绿色体系。
- 积分、资源、团队数据采用“核心指标”同款横向指标样式，并直接复用项目现有彩色指标图标资源。
- 最近收支、团队空间改为当前首页右栏同款白色卡片和紧凑列表样式。
- 不恢复个人空间、姓名、邮箱或 Basic 信息。

### 3. 统一团队与费用页面
- 团队管理、积分中心、资源包、套餐页统一使用当前项目的白色卡片、10px 圆角、轻阴影和紧凑信息层级。
- 移除突兀的边框堆叠和过强色块；状态仍使用 Semi UI 原生语义色。
- 业务图标按含义使用当前项目同类柔和彩色图标，不再统一使用蓝色。
- 表格、按钮、输入框、标签、分页继续使用来也主题 Semi UI 组件。

## 技术约束
- 所有公有云代码继续只放在 `src/cloud`，不与私有部署业务逻辑混合。
- 复用现有项目资源与全局主题变量，不引入新的品牌色或另一套设计令牌。
- 不修改现有公有云功能、数据和跳转关系。
- 完成后检查首页、团队管理、积分、资源包、套餐五个页面的桌面端显示、横向溢出、交互与构建状态。
