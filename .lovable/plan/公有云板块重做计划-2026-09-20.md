# 公有云板块重做计划

## 目标
参考图只用于理解公有云业务功能，不复刻其中的 UCI Cloud 品牌。公有云仍保持独立代码目录，但视觉、Logo、图标、组件和交互规范统一采用当前 APA 项目。

## 功能理解
- **首页**：用户进入公有云后的工作台，集中查看个人积分、专项资源、团队数量和当前套餐；从“我的产品”进入已开通产品；查看最近积分收支和团队空间。
- **团队管理**：区分“我拥有的团队”和“我加入的团队”；团队所有者可查看成员、邀请成员、取消邀请和移出成员；团队成员只查看自己的角色、加入时间、共享积分与套餐。
- **费用与资源**：按当前使用主体（个人空间或团队）查看积分账户、积分明细、专项资源包，以及套餐订阅；支持切换页签、自动续费、查看账单、升级套餐或联系销售。

## 视觉与结构整改
1. 公有云继续放在 `src/cloud/`，与私有部署业务逻辑隔离。
2. 删除自创的 UCI Cloud Logo、深色侧栏和独立紫色品牌体系。
3. 使用当前项目的 LAIYE Logo、Source Han Sans、Lucide 图标、Semi UI 来也主题和现有侧栏交互样式。
4. 页面外框采用当前项目统一布局：浅灰工作区、8px 内容容器、24px 全局内边距、顶部淡蓝晕影、8–10px 卡片圆角。
5. 公有云侧栏保留“首页 / 团队管理 / 费用与资源”三项，但样式与当前 APA 左侧导航一致；底部使用项目统一的黑色用户头像与用户入口。
6. 首页去掉参考图中的大面积深色横幅，改为当前项目首页的问候标题与模块化卡片；保留参考图中的业务信息和入口。
7. 团队管理与费用页使用 Semi UI 的 Button、Tabs、Tag、Dropdown、Input、Progress、Switch 等组件，统一状态颜色和操作反馈。
8. 移除组件中的硬编码品牌色和装饰圆形，颜色改用 Semi 语义变量。

## 验收
- `/cloud/home`、`/cloud/teams`、`/cloud/billing/credits|packs|plans` 均可正常访问与切换。
- 邀请、取消邀请、续费开关、套餐操作、成员操作均有可用反馈。
- Logo、导航、图标、按钮、卡片和文字层级与当前 APA 项目一致。
- 不再出现 UCI Cloud 品牌或独立深色侧栏。
- 通过类型检查与桌面端页面截图检查。
