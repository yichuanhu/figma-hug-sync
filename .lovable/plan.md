

# 需求中心前端设计方案（修订）

## 澄清：Mock 数据语言规则

- **UI 标签/表头/按钮/提示等**：通过 i18n 控制，中文环境显示中文，英文环境显示英文
- **Mock 业务数据内容**：统一使用英文，模拟真实英文业务数据

示例：

```text
┌──────────────────────────────────────────────────────┐
│  需求标题              │ 所属部门  │ 审批状态  │ 优先级  │   ← 中文表头 (i18n)
│───────────────────────│──────────│──────────│────────│
│  Monthly Report Auto  │ Finance  │ 待审批    │ 高     │   ← 数据英文，状态/优先级走i18n
│  Order Processing...  │ Sales    │ 已通过    │ 中     │
└──────────────────────────────────────────────────────┘
```

具体规则：

| 字段类型 | 语言 | 说明 |
|---------|------|------|
| 需求标题、描述、业务背景 | **英文** | mock 业务数据 |
| 部门名称 | **英文** | mock 数据 (Finance, IT, HR) |
| 人名 | **英文** | mock 数据 (John Smith, Sarah Chen) |
| 分类值 | **英文** | mock 数据 (Supply Chain, Manufacturing) |
| 联系人信息 | **英文** | mock 数据 (john@example.com) |
| 状态标签 (审批/开发/运营) | **i18n 中文** | 待审批、已通过、开发中等 |
| 优先级 | **i18n 中文** | 高、中、低 |
| 表头/Label/按钮/提示 | **i18n 中文** | 所有 UI 文案走翻译 |
| 时间 | 标准格式 | 2026-03-15 10:30 |

其余设计方案（目录结构、路由、UI视觉规范、数据层、实施阶段）与上一版完全一致，仅 mock 数据语言规则按上述修订。
