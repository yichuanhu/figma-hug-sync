## 目标

调整「开发中心 > 命令库」列表页的列与行操作，使其符合命令库（共享型资产）的语义。

## 一、列调整

| 变更 | 说明 |
| --- | --- |
| 移除「适用平台」列 | 整列删除（列表不再展示 platforms 标签） |
| 「当前版本」→「默认共享版本」 | 仅改列标题，数据仍取 `current_version`，为空显示 `-` |
| 「描述」→「命令库介绍」 | 仅改列标题，数据仍取 `description`，保留单行省略 + Tooltip |

调整后列顺序：命令名称、状态、默认共享版本、所属部门、创建者、命令库介绍、更新时间、操作。

筛选区不变（顶部筛选中的「适用平台」条件保留，仍可按平台过滤；如需一并去掉请告知）。

## 二、操作项调整

行末「更多」下拉菜单：

- 移除「上传版本」（版本上传仍可在详情抽屉的「版本」Tab 内进行）
- 新增「协作者」（放在「编辑」之后、「删除」之前），点击打开统一的协作者管理面板
- 保留「编辑」「删除」

菜单最终顺序：编辑 → 协作者 → 删除。

## 技术细节

- 主要改动文件：`src/pages/Development/CommandLibrary/index.tsx`
- 协作者复用现有 `useCollaboratorAction` Hook + `CollaboratorPanel`，与流程/参数/凭据等模块保持一致的交互与权限展示（统一 MAX 权限合并、无级联继承）。
- `src/api/index.ts` 的 `CollaboratorAssetType` 增加 `'COMMAND'` 取值，供命令库资产使用；协作者数据继续走现有 mock。
- 若移除后 `Tag`、`Upload` 图标等 import 不再被使用，一并清理，避免 lint 报错。
- 纯前端原型，无后端改动。
