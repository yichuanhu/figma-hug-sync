# 公有云首页重构计划

## 目标
- 彻底移除首页中的头像、姓名、邮箱、个人空间等用户身份信息。
- 减少卡片拼接感，建立“产品入口优先、资产状态辅助、业务动态收尾”的清晰层级。
- 延续当前 APA Logo、侧栏、图标与 Semi UI 来也主题，不另造视觉体系。

## 页面调整
1. 首页顶部改为简洁欢迎区，并在同一区域放置积分、专项资源、团队三个轻量数据摘要。
2. “我的产品”改为首页主要区域，三个产品以完整入口呈现，突出产品名称、用途、最近使用和进入动作。
3. 最近收支与团队空间改为下方双栏数据面板，统一标题、行高、分隔线和操作入口。
4. 移除重复的首页标题说明、个人身份卡片和“个人空间”相关可见文案。
5. 收紧留白、边框、圆角和阴影，保证 1136×842 首屏信息完整且无横向滚动。

## 验收
- 首页不出现用户头像、姓名、邮箱、“个人空间”或 Basic。
- 产品、资产、收支、团队四类核心信息均可见，原有跳转继续可用。
- 页面无内容溢出、运行错误，样式与公有云其他页面保持一致。
